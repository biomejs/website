## How to add your plugin

If you want to add your plugin to the list:
1. Open the <a href="https://github.com/biomejs/website/edit/main/src/content/plugins.json" target="_blank" rel="noopener">Content Collection file</a>
2. Add a new entry to the bottom of the list. We require the following information for each package:
   - `id`: The name of the package that is published on npm. Examples: biome-plugin-foobar, @org/biome-plugin-foobar.
   - `metatadata`: An object that contains additional data:
      - `website`: The website of the plugin, if it exists. Must be an URL.
      - `repository`: The repository of the plugin, if it exists. Must be an URL.
      - `description`: A brief explanation of the package. Explain what the plugin offers.
3. Send a PR. A member of the team will merge it.


## What this page isn't

This isn't a repository or registry for plugins. The team doesn't take responsibility for the contents of the plugins the users decide the list on this page, or whether they are deprecated.
