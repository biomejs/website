## How to add your plugin

If you want to add your plugin to the list:
1. Open the [content collection file](https://github.com/biomejs/website/edit/main/src/content/plugins.json).
2. Add a new entry to the bottom of the list. We require the following information for each package:
   - `id`: The name of the package that is published on npm (e.g. `biome-plugin-foobar`, `@org/biome-plugin-foobar`).
   - `metadata`: An object that contains additional data:
      - `website`: The website of the plugin, if it exists. Must be a URL.
      - `repository`: The repository of the plugin, if it exists. Must be a URL.
      - `description`: A brief explanation of the package. Explain what the plugin offers.
3. Send a pull request. A member of the team will review and merge it.

:::caution
This isn't a repository or registry for plugins. The team doesn't take responsibility for the contents of the plugins that users decide to list on this page, or whether they are deprecated.
:::
